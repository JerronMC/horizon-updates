to Starling.

Starling v0.2.3 includes an import flow for people coming from Horizon Android. Follow the in-app prompts and keep your old app until you verify everything.

01

Install Starling

Download the current Starling APK from its official GitHub release. It installs as a separate app from Horizon Android.

02

Start the import

On first setup, choose the option to bring worlds and resource packs over. You can also start the process from the title screen.

03

Allow and verify

Close Horizon Android, select the requested folder and grant access. Starling copies the data; it does not remove the originals.

Keep your backup.

Open your worlds in Starling and confirm your resource packs before uninstalling the old app. Do not delete the Horizon Android folder during migration.

Compatibility, migration and mod support at a glance.

Read project documentation
Is Horizon Android still getting stable releases?

Horizon Android 0.7.8 is documented as its last stable release as a separate project. The Android work is being continued under the Starling name.

Which Android device can run current Starling?

The Starling project currently documents a 64-bit Android device with Vulkan support and around 2 GB of free space. Performance and compatibility depend on your hardware and drivers. Check the latest release notes before installing.

Can I move my old worlds to Starling?

Yes. Starling v0.2.3 includes an import option for worlds and resource packs from Horizon Android. It copies the data, so the original remains in the old app's folder. Keep a backup until you verify your worlds.

Can I use Fabric, Forge or NeoForge mods?

No. Java loader mods are not directly compatible. Horizon uses its own mod formats. Check whether a mod is a content .hmod or a native .hnmod and whether it supports your exact Starling build.

What is the difference between .hmod and .hnmod?

.hmod is a content mod. .hnmod is a native mod that needs to be compiled for the target client. Starling's release notes describe which native mods can compile in each build.

Does the APK include Minecraft?

No. You need your own legitimate Minecraft: Java Edition access. The projects are unofficial and are not affiliated with Mojang or Microsoft.

Why do I see a warning or crash on startup?

Vulkan drivers, GPU limits, Android background restrictions and device-specific bugs can affect startup. Try the latest project notes, then report your exact phone model, Android version and relevant logs to the project issue tracker.

Is this an official Horizon or Minecraft website?

No. Horizon Updates is an independent community fan site. For downloads and authoritative project information, use the linked official Horizon and GitHub project pages.
