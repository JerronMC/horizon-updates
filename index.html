What it is

Same game. Native speed.

Horizon rebuilds the Minecraft: Java Edition experience as a native Rust engine, checked against the original with differential tests. The Android port brings it to your phone.

Your own copy

A standalone engine you install and run — no Java runtime to babysit, no heavyweight launcher stack.

Native on three platforms

Builds for Windows, macOS and Linux on desktop — plus a Vulkan-powered build for Android.

Open source

Built in the open on GitHub with a growing community of contributors and frequent releases.

Horizon for Android

Built for touch.

The Android port (Starling) ships Vulkan rendering, editable touch controls and sandboxed native mods.

Vulkan rendering

Multiple render modes with resolution scaling to match your phone.

Editable touch controls

Move, resize and fade every button. Four schemes: joystick or D-pad with tap or crosshair aiming.

Native .hmod mods

Sandboxed code mods run on 64-bit builds. Resource packs are supported too.

Java multiplayer

Join Java Edition servers with verified resource downloads.

Keystore sign-in

Account status is stored with the Android Keystore. Sign-in is still in development.

Native audio & haptics

Low-latency AAudio sound, Android keyboard and clipboard, and phone vibration.

Android 9 and up

Requires a Vulkan-capable device. Builds for arm64, 32-bit ARM, x86 and x86_64.

Original resources

The APK downloads original Minecraft resources from Mojang at runtime.

Not supported yet: source-only .hnmod mods, and Fabric/Forge Java code.

Questions

Good to know.

Which APK should I download?

Most modern phones need arm64-v8a. Older 32-bit phones use armeabi-v7a. The x86 and x86_64 builds are for emulators and some Chromebooks.

Where do I get the PC version?

Desktop builds for Windows, macOS and Linux are on playhorizon.dev.

What does “Rust Edition” mean?

Horizon is a rebuild of the Minecraft: Java Edition experience as a native engine written in Rust, aimed at speed and low resource use.

Does it include Minecraft?

The Android APK downloads the original Minecraft resources from Mojang at runtime. The project code itself does not bundle Minecraft assets.

How do I check my download is genuine?

Each release includes a SHA256SUMS.txt file. Compare it with the checksum of the APK you downloaded.

Is this the official site?

No. This is an unofficial fan page. For official information, use playhorizon.dev and the GitHub repository.
